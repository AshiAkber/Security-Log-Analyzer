
# Lab Report: Security Log Investigation

## Aim
To analyze authentication logs and identify suspicious
patterns of failed login attempts.

## Algorithm
1. Start the program.
2. Open the security log file.
3. Read each line.
4. Identify failed login entries.
5. Extract the username.
6. Count failures for each user.
7. Flag users with three or more failures.
8. Display the findings.
9. Stop the program.

## Procedure
1. Create a sample security log.
2. Write the Python log analysis program.
3. Save both files in the same directory.
4. Run the program using Python.
5. Observe the failed login counts and alerts.

## Result
The program analyzes authentication logs and reports
users with repeated failed login attempts.

## Limitation
Repeated failures alone do not establish an attack.
The results should be reviewed with timestamps,
source addresses, and other available evidence.
